Dashboard setup

How to run the FarmTech Africa smart irrigation dashboard (2D map, 3D farm, PostGIS data, sign-in). ← Back to the website

1. Install

You need Node.js, plus Tailscale connected for the PostGIS database. In the inner GMT320-Osimele folder (the one with package.json):

npm install

2. Settings file (server/.env)

Copy server/.env.example to server/.env and fill in the real values. .env is in .gitignore, so the passwords never go to GitHub.

# PostGIS (ask the team for the password)
DB_host=100.105.1.96
DB_port=5432
DB_user=postgres
DB_password=...
DB_name=ftagisdatabase
DEMO_MODE=auto

# Sign-in passwords per role
PASS_STAFF=...
PASS_MANAGER=...
PASS_RESEARCHER=...
PASS_ADMIN=...
AUTH_SECRET=...   # any long random text

3. Run

npm run server

Then open http://localhost:3000/src/dashboard.html. Check the database connection at /api/health.

Without the server, the 2D and 3D maps still open (for example with Live Server or npm run dev), but sensor recordings, the irrigation decision and sign-in need the server.

4. Other commands

CommandWhat it does
npm run dbcheckLists every database table with its columns and a sample row.
npm run indicesMakes the NDVI, NDRE and canopy temperature images from the MicaSense Altum orthomosaics in C:\Users\noesi\Downloads\drone_images (date from the name, e.g. 251209ortho.tif = 9 Dec 2025). Refresh the dashboard afterwards.
npm run devVite development server for the website.

5. Who sees what (sign-in)

Without signing in, everyone sees the farm layout and the irrigation decision. The rules live in src/roles_config.js; the server checks the same file before it sends any recordings.

RoleSees in addition
Farm operations staffSensor and weather-station locations, SIEMENS water data (tank levels)
Farm managerAll locations, SIEMENS water data, weather-station recordings
ResearcherAll locations, soil-moisture recordings and pillars, drone NDVI / NDRE / temperature, weather-station recordings
Master adminEverything

6. Where to change things

FileChange it to…
server/sensor_tables.jsLink a map sensor (its id in sensor.geojson) to its database table.
src/decision_config.jsChange the irrigation decision thresholds (dryness, rain, ETo, tanks).
src/roles_config.jsChange what each role may see.
src/dashboard_config.jsChange the server address, data files and the weather-station rings.
